
## Scientific writing
- Use British English.
- Follow MNRAS scientific writing conventions.
- Maintain a concise, formal academic tone.
- Preserve the original scientific meaning.
- Never invent numerical results or references.
- Do not change scientific conclusions without approval.

## LaTeX
- Use the existing document structure.
- Preserve existing labels and citation keys.
- Do not remove references without checking them.
- Compile using latexmk.
- Check for undefined references and citations.

## Python
- Follow PEP8 conventions.
- Use NumPy and SciPy where appropriate.
- Preserve existing public APIs.
