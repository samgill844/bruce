bruce.template_match
--------------------

`Source <https://github.com/samgill844/bruce/blob/main/src/bruce/template_match/template_match.py>`__

.. py:function:: bruce.template_match.template_match_lightcurve(time, flux, flux_err, normalisation_model, period=1.0, radius_1=0.2, k=0.2, incl=np.pi / 2, e=0.0, w=np.pi / 2.0, c=0.7, alpha=0.4, cadence=0, noversample=11, light_3=0.0, ld_law=-2, accurate_tp=1, jitter=0.0, offset=0, time_step=None, time_trial=None)

   Compare fixed transit templates with a supplied baseline at trial epochs.

   :param time: Sorted one-dimensional NumPy time array, in days.
   :param flux: Flux array on the time grid; relative flux for models.
   :param flux_err: Positive one-sigma flux uncertainties, in flux units.
   :param normalisation_model: Baseline flux array on the observation grid; transit flux multiplies this baseline.
   :param period: Orbital period in days.
   :param radius_1: Scaled primary radius R_star/a. For batch searches, supply all three geometry parameters as one-dimensional NumPy arrays.
   :param k: Companion-to-primary radius ratio R_companion/R_star. For batch searches, supply all three geometry parameters as one-dimensional NumPy arrays.
   :param incl: Orbital inclination in radians. For batch searches, supply all three geometry parameters as one-dimensional NumPy arrays.
   :param e: Eccentricity, with 0 <= e < 1.
   :param w: Argument of periastron in radians.
   :param c: Power-2 limb-darkening coefficient (or linear coefficient for ld_law=1).
   :param alpha: Power-2 limb-darkening exponent.
   :param cadence: Full exposure duration in days; zero means instantaneous evaluation.
   :param noversample: Exposure subsample count; odd and at least 3 when cadence is positive. Default 11.
   :param light_3: Contaminating light divided by target light.
   :param ld_law: Law selector: 2 power-2, 1 linear, 0 uniform, -1 box with depth k, -2 single-event power-2.
   :param accurate_tp: 1 minimises projected separation for epoch-to-periastron conversion; 0 uses the edge-on conjunction approximation.
   :param jitter: Additional independent scatter added in quadrature to uncertainties; same units as the observations.
   :param offset: Include the variance-dependent logarithmic term if 1/True; omit if 0/False. Gaussian additive constant is omitted.
   :param time_step: Trial-epoch spacing in days; None selects circular transit width/20.
   :param time_trial: Explicit NumPy array of trial epochs; overrides automatic epoch-grid generation.
   :returns: Tuple (time_trial, score). Scalar geometry gives a 1D score; array geometry gives axes (epoch, radius_1, k, incl). Score is 2*(logL_transit-logL_baseline).
