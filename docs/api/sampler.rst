Sampling and likelihood utilities
=================================

.. This file is generated by docs/scripts/generate_api.py.

These names are exported by ``bruce.sampler``. Install the analysis extra.
Log priors and likelihoods here use the **larger-is-better** sign.
The helpers do not establish MCMC convergence: check mixing, effective
sample size and autocorrelation for your scientific application.

   Evaluate pointwise Gaussian log likelihoods.

   :param y: Observed values.
   :param yerr: Positive one-sigma measurement uncertainties.
   :param model: Predicted values matching the observations.
   :param jitter: Additional independent scatter added in quadrature to uncertainties; same units as the observations.

.. py:function:: bruce.sampler.bic(llf, nobs, df_modelwc)

   Calculate the Bayesian information criterion.

   :param llf: Maximised log likelihood (not negative log likelihood).
   :param nobs: Number of observations.
   :param df_modelwc: Number of fitted parameters, including any constant.
   :returns: -2*llf + log(nobs)*df_modelwc.

.. py:function:: bruce.sampler.intilise_and_run_sampler(func, theta, nsteps=5000, moves=..., nthreads=12, progress=True, refit=True, backend='Backend.h5', args=None)

   Construct and optionally run emcee with a multiprocess pool. The misspelling is part of the current API.

   :param func: Callable returning log posterior (larger is better), optionally with emcee blobs.
   :param theta: One-dimensional initial parameter vector.
   :param nsteps: Number of MCMC steps per walker.
   :param moves: Weighted emcee move objects; source defaults use DE and DESnooker moves.
   :param nthreads: Number of multiprocess worker processes, not OpenMP threads.
   :param progress: Show the emcee progress indicator.
   :param refit: True resets the backend and runs a new chain; False constructs a sampler around the existing backend without running.
   :param backend: HDF5 backend filename, or None for an in-memory chain. refit=True resets an existing file.
   :param args: Additional positional arguments passed by emcee to func.
   :returns: emcee EnsembleSampler. Uses 2*len(theta) walkers; a resumed backend is not advanced when refit=False. Use a __main__ guard in scripts.
