Data utilities
==============

.. This file is generated by docs/scripts/generate_api.py.

Processing functions below are exported by ``bruce.data`` unless a
submodule path is shown. Archive helpers require network access; the
institutional helpers additionally require a local implementation configured
with BRUCE_LOCAL_ARCHIVE; it is not included in public distributions.
``bruce.data.load_NASA_exoplanet_archive(unique_entries=False)`` is a lazy
alias for the fully documented submodule function below.

.. py:function:: bruce.data.flatten_data_with_function(time, flux, method='savgol', max_median=0, npoly=3, Nmaxfilter=11, Nmedianfilter=19, splinesmooth=100, SG_window_length=10, SG_polyorder=3, SG_deriv=0, SG_delta=1.0, SG_iter=1, SG_sigma=3)

   Estimate a trend with optional maximum/median preprocessing. This returns the trend, not divided flux.

   :param time: Sorted one-dimensional NumPy time array, in days.
   :param flux: Flux array on the time grid; relative flux for models.
   :param method: Trend estimator: poly1d, spline or savgol.
   :param max_median: 0 disables preprocessing; 1 applies maximum then median filter; 2 applies median then maximum filter.
   :param npoly: Polynomial degree for poly1d.
   :param Nmaxfilter: Maximum-filter window size in samples.
   :param Nmedianfilter: Median-filter window size in samples.
   :param splinesmooth: UnivariateSpline smoothing factor.
   :param SG_window_length: Savitzky-Golay window length in samples; choose an odd length larger than SG_polyorder.
   :param SG_polyorder: Savitzky-Golay polynomial order.
   :param SG_deriv: Derivative order; zero returns the smoothed trend.
   :param SG_delta: Sample spacing for Savitzky-Golay derivatives.
   :param SG_iter: Number of clipping/filter passes.
   :param SG_sigma: Residual clipping threshold in standard-deviation units.
   :returns: Trend array on the input grid; divide the original flux by it to flatten.

.. py:function:: bruce.data.data_processing.find_optimal_ngts_filter_window(time, flux, windows=..., verbose=False, tolerence=0.05, theoretical_noise=None)

   Select a window using measured versus target 30-minute scatter.

   :param time: Sorted one-dimensional NumPy time array, in days.
   :param flux: Flux array on the time grid; relative flux for models.
   :param windows: Candidate median-filter time windows; default scans 10.49 down to 0.5 days.
   :param verbose: Print progress or results when True.
   :param tolerence: Allowed fractional excess over theoretical_noise (historical spelling).
   :param theoretical_noise: Required positive target scatter in ppm per 30-minute integration.
   :returns: Tuple (window, time, flux, flux_err, counts, trend); uses a two-day fallback if no trial meets the target.
