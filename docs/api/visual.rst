.. py:function:: bruce.visual.animate_orbit(planets_params, t=..., line_alpha=0.3, zoom_primary=False, save_gif=False, gif_path='orbit.gif', fps=30)

   Display independent Keplerian orbits and optionally save a GIF.

   :param planets_params: List of dictionaries with t_zero, period, radius_1, k, incl, e, w and optional label; same conventions as lc.
   :param t: Time samples in days; default np.linspace(-0.1, 0.1, 1000). One frame per sample.
   :param line_alpha: Opacity of the trajectory lines.
   :param zoom_primary: Limit the sky-plane view to +/-1.5 stellar radii if True.
   :param save_gif: Save an animated GIF using Pillow if True.
   :param gif_path: Destination GIF filename.
   :param fps: Saved GIF frames per second.
   :returns: None. Opens a Matplotlib figure and calls show(); optionally writes gif_path.
